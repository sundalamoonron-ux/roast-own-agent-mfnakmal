One line roasting my own AI agent: it turned "delete one line" into a 12-step migration, a rollback plan, and a post-mortem for a line that was never deleted.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (one line, 129 characters).

## How the roast was picked

Ten original candidates were drafted in `candidates.md`, shortlisted to six, then played in a pairwise round-robin judged on the house brief (funny first, then fresh, then tight). The winner, C7, won all 5 of its games; runners-up C3 and C8 won 3/5 each.
